# SlackMemberCheck

Googleフォームの回答者がSlackワークスペースに参加済みかどうかを自動で突合し、スプレッドシート上で可視化する Google Apps Script です。あわせて「Slackにはいるが、回答が見つからないメンバー」を別シートに書き出します。

## できること

**1. 回答者がSlackに参加済みかを自動チェック**

回答シートのA列（加入準備WS参加チェックボックス）に、Slackへ参加済みの回答者を自動でチェックします。

判定はまずメールアドレスで照合し、見つからなければ氏名で照合します。すでにチェック済み（TRUE）の行はそのまま保持され、再判定されません。

**2. 取りこぼしているSlackメンバーを抽出**

「Slack未対応」シートに、Slackにはいるのに対応する回答が見つからないメンバーの一覧を書き出します。フォロー漏れの確認に使えます。

## セットアップ

1. Slack App を作成し、**Bot Token Scopes** に次の2つを付与してワークスペースにインストールする
   - `users:read` … メンバー一覧の取得
   - `users:read.email` … メンバーのメールアドレス参照
2. 発行された Bot Token を、スクリプトプロパティ `SLACK_BOT_TOKEN` に設定する
3. 回答シートは次の前提で読み取られます
   - シート名: `フォームの回答 1`
   - 列: A=参加チェック / B=タイムスタンプ / C=メールアドレス / D=お名前

## 使い方

`checkSlackMembership` を実行すると、結果がA列のチェックと「Slack未対応」シートに反映されます。

一度チェックが付いた行は再判定されません。改めて評価したい行は、A列を空欄に戻してから実行してください。

## うまく一致しないとき

- フォームとSlackでメールアドレスが異なる、または表示名と氏名が異なる（ニックネーム・旧姓・別表記など）場合は一致しません
- bot・無効化済み・メール未設定のSlackユーザーは突合の対象外です
